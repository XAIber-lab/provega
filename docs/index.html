ProVega

ProVega extends Vega-Lite. Add one provega block to any Vega-Lite spec and the chart becomes progressive: chunked computation, execution controls, progress and quality indicators, change highlighting, and others. Remove the block and it is plain Vega-Lite again.

How it works

One block on top of Vega-Lite

All progressive constructs live under a single top-level property. Marks, encodings and native transforms are untouched and refine each partial result. ProVega supports data chunking, process chunking and mixed chunking, and accepts complete or streamed input (WebSocket, Socket.IO).

Vega-Lite
{ "data": { "url": "fars.csv" },
  "mark": "circle",
  "encoding": { "longitude": …, "latitude": … },
+ ProVega
  "provega": {
    "progression": {
      "chunking": {
        "type": "data",
        "reading": { "method": "sequential",
                     "chunk_size": 2000, "frequency": 200 }
      },
      "control": { … },
      "monitoring": { "change": { "mark": true } }
    }
  }
}

Use case 1: 5.6 × 10⁵ fatal US road crashes (FARS 2001–2009), one update every 250 ms.
